# Marketing Budget vs. Actual Sales Analysis

A comprehensive data analysis, linear regression modeling, and statistical evaluation project examining the relationship between marketing expenditure and actual sales performance.

---

## 📊 Project Overview
This repository contains statistical analysis scripts, visualizations, and a complete documentation based on a dataset of **222 observations**. The primary objective is to quantify how marketing budgets impact sales, evaluate model accuracy, and build a reliable predictive linear regression model.

---

## 🚀 Key Findings & Model Parameters
* **Correlation Coefficient ($r$):** `0.8367` (Strong positive linear relationship)
* **Slope / Coefficient:** `0.0495`
* **Intercept:** `3.3169`
* **R-squared ($R^2$) Value:** `0.7001` (Indicates that ~70% of the variance in sales is explained by the budget)
* **Outliers Detected:** `0` (Using the Interquartile Range method)
